# 香料斷流 — v0.3.0

以《沙丘》小說與新版電影為風格依據的非官方單人第一人稱射擊試作。不是電影遊戲，也不是授權產品。場景、角色、貼圖、聲音全部在瀏覽器內由程式即時生成，不含任何電影圖片、音樂或外部模型。

v0.3 做了兩件事：把畫面與手感整體重做到參考作品《幾貓》的層級，並把「清兩波敵人、走到終點」的切片擴成有任務互動、路線取捨、事件增援和登機撤離的完整單關。

## 開始遊玩

開啟 `dist/index.html`（與 `dist/Spice_Interdiction_v0.3.html` 內容相同）。需要支援 WebGL 2 的瀏覽器。單一 HTML 已內嵌 Three.js 與全部程式，設有 `connect-src 'none'`，不需要網絡，也不需要安裝任何東西。

| 操作 | 輸入 |
|---|---|
| 移動／視角 | WASD／滑鼠 |
| 開火／瞄準 | 左鍵／按住右鍵 |
| 互動 | 按住 E |
| 換彈／急救包 | R／Q |
| 衝刺／蹲伏／跳躍 | Shift／C／Space |
| 戰術地圖／暫停 | M／Esc |

觸控裝置有搖桿與按鈕，但只做過模擬環境的初始化，沒有真機驗證。

## 這一關

你是弗瑞曼突襲者，目標是哈肯能的第九採收前哨。

岩隙出發 → 選擇西側維修道或東側採收場 → **取得勘測紀錄**、**停止採收機**（次序不限）→ 穿過北門**啟動接應信標** → 守住接應坪 75 秒 → 撲翼機降落後**按住 E 登機** → 離場，沙蟲吞掉被留下的採收機 → 結算。

**任務不要求殲滅敵人。** 驗收裡有一次零擊殺、零開火的通關。

| 路線 | 內容 | 後果 |
|---|---|---|
| 西側維修道 | 守衛少，控制塔牆上有警報繼電器 | 切斷後，前哨無法呼叫增援；主目標完成時的回防隊與撤離追兵都會縮編 |
| 東側採收場 | 守衛多，正面交戰 | 補給站補滿彈藥、修補蒸餾服、給兩個急救包 |

筒倉脊線有兩處橫向通道，兩條路可以中途互換；勘測紀錄在西、採收機在東，所以不論從哪邊進，都要橫越一次。

幾條規則：

- 被發現（或在牆內開火）後，守衛有約 5 秒拉響警報；警報帶來一波四人的增援，只會來一次。事後再切繼電器只能讓警笛停下。
- 北門與採收作業連鎖：採收機不停，門不開。信標需要紀錄裡的頻率：沒有紀錄，控制台拒絕輸入並說明原因。
- 接應機沒落地不能登機。登機後進入離場演出，地面火力不再造成傷害。目前沒有登機逾時失敗。
- 完成兩個前哨目標時儲存一個檢查點。死亡後可從檢查點重試，任務旗標、警報、補給、北門、採收機、敵人和撤離狀態會一併還原。
- 暫停、開地圖、切換視窗時，戰鬥、互動進度、沙蟲訊號與接應倒數一起凍結。
- 增援只從玩家看不見、距離 20 公尺以上的位置進場；同時存活上限 14 人，超出的在隊列等候。

沙蟲仍然只是環境壓力：牠不上岩地，不造成傷害，沒有頭目戰。地震儀隨撤離進度分三級升高。

## 相對 v0.2 改了什麼方案

v0.2 與參考作品的差距不在某一個特效，而在生產方式：每個物件是幾個方塊，所有材質共用一張噪聲做弱對比疊色，光照平、沒有空氣感。參考作品則是高密度的場景零件、強逆光與霧、每個表面都有多尺度細節。所以這一版沒有在舊模組上補丁，而是換掉了底層：

| 項目 | v0.2 | v0.3 |
|---|---|---|
| 幾何 | 每個方塊一個 Mesh | `Batch` 合批：帶倒角的基本體寫入同一緩衝，頂點色著色，一個區域一到兩次繪製 |
| 材質 | 一個疊色函式 | 三個著色器家族：礦物（模板接縫、拉桿孔、流痕、積沙、岩層）、硬表面（掉漆、刮痕、積塵、布紋、自發光）、沙地（風紋、香料色斑、閃爍沙粒、貼地流沙） |
| 天空與環境光 | 漸層球 + 半球光 | 解析式天空（塵帶、前向散射、卷雲、雙月）並捲積成環境光；高度霧朝太陽方向變暖 |
| 陰影 | 固定 144 m 範圍 | 4096 陰影圖跟隨玩家、對齊紋素、邊緣淡出 |
| 後處理 | 單層泛光 | 六層無閾值泛光、眼睛適應、鏡頭髒污與光斑、光束、熱擾動、色散、瞄準時周邊柔化、電影式曲線與調色 |
| 場景 | 一棟塔、一台機器、六個掩體 | 階梯式控制塔、防沙牆與三座門、筒倉脊線、管架、儲槽、發電機、風阱、天線塔、貨箱、履帶車、接應坪 |
| 採收機 | 方塊組合 | 四組履帶艙、壓力艙、甲板建築、旋風分離器、排氣管、滾筒刀具；會停機 |
| 撲翼機 | 橢球加四片板 | 玻璃座艙、尾桁、六片拍動的翼，有進場、降落、開門、離場 |
| 敵人 | 剛體零件、直線逼近 | 15 根骨骼的蒙皮模型；巡邏、察覺、依導航網格找射擊位、蹲伏、三種倒地；兩個兵種 |
| 武器 | 過大、遮擋畫面 | 重新建模的 K-18；腰射／瞄準、慣性、步伐、衝刺、落地、彈簧後座、四拍換彈、互動時放低；反射隨視角轉動 |
| 特效 | 每顆粒子一個材質 | 兩個實例化粒子池（受光沙塵、加色火花）、飛行曳光、彈痕、彈殼 |
| 音效 | 單層 | 混響、空間定位、採收機／撲翼機／警報／沙蟲循環聲，隨緊張度變化的鋪底與鼓點 |

## 畫質選項

| 選項 | 陰影 | MSAA | 說明 |
|---|---:|---:|---|
| 低 | 2048 | 0 | 0.8 倍解析度，關閉環境遮蔽與部分後處理 |
| 中 | 2048 | 0 | 完整後處理 |
| 高 | 4096 | 4 | 預設 |
| 極高 | 4096 | 4 | 高 DPI 螢幕以 2 倍解析度渲染 |

設定（畫質、難度、視野、音量、靈敏度、反轉、減少晃動）存在瀏覽器本機。

## 原始碼與重建

只需 Python 3：

```sh
python3 build.py
```

輸出 `dist/Spice_Interdiction_v0.3.html`、`dist/index.html` 與 `dist/build.json`（SHA-256 與來源清單）。

| 檔案 | 職責 |
|---|---|
| `src/core.js` | 數學、噪聲、基本體、`Batch` 合批、碰撞（方盒與橢圓柱） |
| `src/materials.js` | 噪聲貼圖、三個著色器家族、徽記圖集 |
| `src/sky.js` | 天空、太陽、環境光、高度霧、跟隨式陰影 |
| `src/terrain.js` | 高度場、沙丘、岩體生成、遠景 |
| `src/render.js` | HDR 後處理管線 |
| `src/kit.js` | 場景零件庫 |
| `src/world.js` | 關卡配置、碰撞、動態物件、導航網格與尋路 |
| `src/harvester.js`、`src/thopter.js`、`src/worm.js` | 採收機、撲翼機、沙蟲 |
| `src/weapon.js`、`src/enemies.js`、`src/effects.js`、`src/audio.js` | 武器、敵人、特效、聲音 |
| `src/input.js`、`src/hud.js` | 輸入、HUD 與戰術地圖 |
| `src/mission.js` | 目標、互動、警報、增援、檢查點 |
| `src/extraction.js` | 信標、倒數、追兵、登機、離場 |
| `src/game.js`、`src/main.js` | 玩家、戰鬥、狀態機、啟動 |
| `src/dev/` | 開發用檢視頁（`python3 build.py --dev world kit.js world.js harvester.js thopter.js`） |
| `tests/` | 測試機器人與驗收腳本 |

## 驗證

`node tests/run.js` 需要 Node、Playwright 與 Chromium；遊戲本體不需要。結果見 `docs/TEST_REPORT.md` 與 `tests/results.json`。

- **兩條路線的完整通關**由 `tests/bot.js` 透過輸入層完成：按鍵、轉向、扣扳機、按住互動鍵。不瞬移、不改任務狀態、不移除敵人。瞄準是腳本控制的，所以它的用時與命中率不代表真人。
- 其餘檢查為了快速到達某個狀態，會用測試夾具放置玩家或直接扣血，報告裡逐項標明。
- `screenshots_v03/` 是同一份 HTML 的實際 WebGL 畫面，為了重現特定時刻用夾具擺位；不是通關錄影。

## 還沒做到、需要你親自看的

- **沒有人實際玩過。** 手感、難度、節奏、音量平衡全部沒有人工驗收；自動化通過不等於好玩。
- 所有畫面都在軟體 GPU（SwiftShader）上產生，每幀數秒。**真實硬體上的幀率完全未知**；世界通道約 100 次繪製、60 萬三角形（另有陰影通道），後處理偏重，中低階顯示卡可能需要降到「中」。
- 未在 Mac、Safari、真實手機上測試；未驗證雙擊本機檔案以外的啟動方式。
- 與參考作品相比仍有差距：敵人只有程序動畫，沒有手工關鍵影格；沒有屏幕空間反射；沙蟲在離場鏡頭裡是塵柱中的軀幹，口部細節看不清；控制塔與牆面在近距離仍偏素。
- 敵人不會翻越掩體、不會投擲物，卡住時靠重新尋路脫困。
