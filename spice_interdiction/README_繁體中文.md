# 香料斷流 — v0.2.0

第二階段：表現與手感修整。這是以《沙丘》為靈感的非官方單人第一人稱射擊試作，不是電影遊戲或官方授權產品。所有場景、角色、貼圖、聲音均在瀏覽器內由程式建立；不包含電影圖片、音樂或外部模型。

## 開始遊玩

使用遊戲 ZIP 時，解壓後開啟 `index.html`；使用本原始碼包時，開啟 `dist/Spice_Interdiction_v0.2.html`。需要可執行 JavaScript、WebGL 2 的瀏覽器。按「進入岩隙」後啟動聲音並要求滑鼠鎖定；Esc 暫停。聊天附件／系統檔案預覽不等於完整瀏覽器執行環境。

遊戲本體沒有網絡依賴，HTML 已內嵌 Three.js、介面及所有遊戲模組，並設有 `connect-src 'none'`。不需要安裝開發工具來遊玩。此環境已驗證斷網狀態下透過瀏覽器載入 HTML 內容並運行；因環境管理政策阻擋 `file://` 導航，未能在這裡驗證雙擊本機檔案的啟動途徑。尚未在使用者的 Mac、Safari 或真實 iPhone 上測試。

## 操作與目標

| 操作 | 輸入 |
|---|---|
| 移動／視角 | WASD／滑鼠 |
| 開火／瞄準 | 滑鼠左鍵／按住右鍵 |
| 換彈／跳躍 | R／Space |
| 衝刺／蹲下 | Shift／C |
| 暫停 | Esc |

從岩隙到採收前哨，清除三名守衛與三名增援，再走入北側接應點完成關卡。低牆、岩石及建築可以阻擋射擊；離開火力一段時間後生命會恢復。觸控介面保留左手移動、右側轉向與動作按鈕，但目前只經過模擬環境初始化測試，未驗證真機操作體驗。

暫停選單提供畫質、視野、音量、靈敏度與「減少鏡頭晃動」。設定沒有跨次開啟持久儲存。

## 本版更新

### 材質、場景與光影

新增多尺度程序化砂岩、風蝕紋理、材質粗糙度與凹凸細節、金屬與布料。沙地改為多尺度風紋，遠景地形與岩層重新調整；岩石底部依地形採樣貼地。採收機增加維修板、散熱風扇、鉚釘、梯子、管線和履帶印；場景增加碎石、布棚、工業標記和接地陰影。

渲染改用 HDR 浮點緩衝、半解析度深度環境遮蔽及深度感知模糊、柔和泛光、屏幕空間遮擋感知光束、金屬環境反射、遠處熱擾動、電影式色調映射、少量顆粒與受傷調色。這些是即時近似，並非光線追蹤或完整物理體積光。

### 武器與反饋

K–18 改為獨立槍身、光學瞄具、槍機、彈匣、扶槍手、手套與袖口。新增彈簧式後座與回復、彈匣抽換及扶槍手動作、瞄準中心校正、槍口火光與短暫照明、彈殼、表面命中粒子與彈痕。彈痕上限 56，短暫特效上限 240，會過期及在重試時清理。

### 守衛

新增髖、膝、踝、肩與頭部的程序化動作，裝甲、面罩與披布。守衛會接近、橫移、短點射與恢復；開火前面罩變亮，三發點射後有間隔，受擊會中斷點射。命中判定使用實際網格與移動頭部標記。沒有完整導航網格、布料物理或布娃娃物理。

### 沙蟲預警

開始遊玩超過 8 秒，並符合「至少兩次擊殺／至少八次射擊／進入前哨較深處」其一時，地底預警自然觸發。事件約 36 秒，經過偵測、接近、掠過、遠離和結束。地震儀、合成低頻聲、鏡頭微震、動態沙脊與遠方沙塵互相配合。暫停時凍結，重試時重置；減少鏡頭晃動會關閉這部分相機震動。

這是環境預警，沒有沙蟲頭目模型、不造成額外傷害，也不阻擋原有撤離條件。已處於事件途中時仍可完成關卡。

## 畫質選項

| 選項 | 陰影尺寸 | MSAA | 主要取捨 |
|---|---:|---:|---|
| 低 | 1024 | 0 | 降低解析度與後處理，優先效能 |
| 高 | 2048 | 4 | HDR、接觸陰影、泛光、屏幕光束 |
| 極高 | 3072 | 4 | 提高陰影與高 DPI 畫面上限 |

實際解析度受視窗和裝置像素比例限制。這些是程式設定，並非所有裝置都能以同樣幀率運行。軟體 GPU 測試不能代表 Mac 或手機效能。

## 原始碼與重建

只需 Python 3：

```sh
python3 build.py
```

輸出為 `dist/Spice_Interdiction_v0.2.html`，SHA-256 和來源列表記錄在 `dist/build.json`。沒有 npm 安裝、雲端建置或素材下載。

| 檔案 | 職責 |
|---|---|
| `src/core.js` | 幾何工具、隨機與共同函式 |
| `src/materials.js` | 生成紋理、程序化材質 |
| `src/world.js`, `src/world_detail.js` | 地形、建築、採收機、碰撞與場景細節 |
| `src/weapon.js` | 第一人稱槍械與獨立活動部件 |
| `src/enemies.js` | 守衛網格、動作與狀態機 |
| `src/effects.js` | 命中、彈殼、粒子與清理 |
| `src/audio.js` | 合成聲音、空間提示與地震聲 |
| `src/render.js` | HDR、深度遮蔽、泛光與合成 |
| `src/atmosphere.js` | 沙蟲預警時序、沙脊與沙塵 |
| `src/input.js`, `src/game.js`, `src/main.js` | 輸入、遊戲流程與啟動 |
| `src/shell.html`, `src/style.css` | 介面與排版 |
| `vendor/` | Three.js r180 與 MIT 授權文字 |

`reference.json` 保留原始參考檔的指紋。原始 `jimao.html` 與 v0.1 交付檔未被修改。

## 驗證與截圖來源

詳見 `TEST_REPORT.md` 和 `tests/*.json`。本版有 24 項原有功能回歸及 24 項第二階段整合測試，另有不啟用測試模式的開始／射擊／暫停檢查。

`tests/verify.py`、`tests/stage2.py`、`tests/normal_smoke.py` 使用 Playwright、Linux Chromium 與 Xvfb；需要自行安裝測試環境，遊戲本體不需要。測試腳本中的 `/usr/bin/chromium` 是本次驗證環境路徑，在其他系統執行測試需改為當地瀏覽器路徑。

`screenshots_v02/01_title.png` 至 `07_seismic.png` 都是同一交付 HTML 的實際 WebGL 截圖。為可重現地展示功能，測試會設定相機位置、瞄準與時間；沙蟲預警圖隱藏守衛以觀察環境。它們不是人工通關錄影，也不是 AI 概念圖。JPG 只做格式轉換，未重繪畫面。

## 品質界線

本版相對 v0.1 已有實際的渲染和手感系統升級，但沒有證據支持「已達到《幾貓》全部畫質標準」。角色、武器模型與動畫仍然簡化，視覺密度、接近觀察時的細緻程度及複雜光照仍有差距；未加入屏幕空間反射、完整體積散射或手工角色動畫。自動化功能通過不等於人工手感或美術驗收。

尚未驗證：Mac／Safari／真實手機、硬件 GPU 幀率、長時間穩定性、人工音訊聽感與難度平衡。
